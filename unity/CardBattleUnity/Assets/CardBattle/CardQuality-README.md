# 原作フォーマットに寄せたカード表示

原作の参考カード画像を枠の背景として使い、中央のイラスト・名前・コスト・Lv・BP・効果をUnityのUIで重ねる試作へ変更しました。画像そのものの加工は行わず、原画像も変更していません。

- 上部：原作の装飾枠、コスト円、英語名の帯
- 中央：新しいイラスト
- 名前帯：スピリット、カード名、系統
- 下部：白地、左に色付きのLv表示と黒いBP、右に効果
- 効果なしの場合は本文を空欄
- 属性シンボルと薄い背景模様は参照画像の該当部分を表示
- 詳細・手札・場のすべてで同じフォーマットを比較

BPが表示されていなかった原因となる2行テキストの切れを避け、LvとBPを別のUI部品にしました。

ビルド・動作確認は未実施です。旧バトルサーバーを停止してから実行してください。

```bash
bash scripts/card-battle-poc.sh build
bash scripts/card-battle-poc.sh start
```

ロビーの「カード表示試作」を開きます。新しい `SpiritCardOriginal.prefab` は初回ビルド時に自動生成されるため、手動で古いPrefabを削除する必要はありません。

枠の画像は今回の参考画像（赤500×713、紫481×695）から表示しているため、拡大時の精細さには限界があります。文字と新しいイラストは別描画です。枠の書体や帯の位置まで完全一致したと保証するものではなく、実際の表示を見ながら調整する段階です。

この変更は品質検証画面のみです。対戦マスタ・効果処理・保存デッキには変更を加えていません。
