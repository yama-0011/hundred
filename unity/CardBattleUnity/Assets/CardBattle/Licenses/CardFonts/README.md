# Card preview fonts

These are visual approximations, not identified original card typefaces.
All font files are distributed under SIL OFL 1.1; family licenses are included here.

| Usage | Font | Source |
| --- | --- | --- |
| Japanese card name | Dela Gothic One | https://github.com/google/fonts/tree/main/ofl/delagothicone |
| English name / level / cores | Tinos Bold | https://github.com/google/fonts/tree/main/ofl/tinos |
| Cost | Tinos Bold Italic | https://github.com/google/fonts/tree/main/ofl/tinos |
| BP | Archivo Black | https://github.com/google/fonts/tree/main/ofl/archivoblack |
| Type / effects | BIZ UDGothic Bold | https://github.com/google/fonts/tree/main/ofl/bizudgothic |
| Tribe / flavor | BIZ UDMincho Regular | https://github.com/google/fonts/tree/main/ofl/bizudmincho |

Tinos license source: https://github.com/googlefonts/tinos/blob/3b4482a99b80ea5fc75f187b1be3120a3f5905b3/OFL.txt
Font assets are embedded for WebGL instead of depending on installed system fonts.
