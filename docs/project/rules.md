# プロジェクトルール

> AI Desktopが生成したファイルです。直接編集せず、AI Desktopで変更してください。

- **必須** Appの内部に踏み込まない（方針）：Hundredは認証、Home、Appの起動、共通設定だけを受け持つ。各Appのデータやテーブルを直接更新しない。
- **必須** 画面の表記は日本語（UI）：UIは日本語を標準とし、英字は製品名・サービス名・定着した略語に限る。同じ概念には常に同じ言葉を使う。詳細は ドキュメント/共通/Hundred-UI表記ルール.md。
- **必須** 内部のユーザー名を表示しない（UI）：Cognitoの内部ユーザー名は画面に出さず、名前かメールアドレスで表示する。
- **必須** 権限はサーバーで判定（セキュリティ）：APIはCognitoのAccess Tokenを検証してから処理する。画面側の判定は表示の出し分けにだけ使う。
- **必須** 秘密情報を保存しない（セキュリティ）：パスワード、APIキー、暗号鍵をリポジトリ、フロントエンド、APIレスポンス、プロジェクト情報に含めない。
- **必須** マイグレーションは追加のみ（データベース）：D1の変更は workers/apps-api/migrations に次の連番でSQLを追加する。本番に適用済みのファイルは書き換えない。
- **必須** 本番への反映は指示があるときだけ（データベース）：本番D1へのマイグレーション適用とデプロイは、本人の指示があるときだけ行う。本番DBを開発用に使わない。
- **推奨** コメントは日本語で概要と責務（コード）：ファイルと名前付きの関数に「概要」と「責務」を日本語で書く。詳細は ドキュメント/コーディング規約/。
- **必須** ファイル名にプロダクト名を付ける（コード）：Hundred専用のファイルは Hundred を接頭辞にする（例：HundredWallpaperBackground.tsx、hundredAuth.ts）。コンポーネントはPascalCase、その他のTSはcamelCase、CSSはkebab-case。
- **必須** 変更後は型チェック（コード）：フロントエンドは npx tsc --noEmit -p . を通す。画面の変更はブラウザで確認したかどうかも報告する。
- **必須** コミットメッセージ（Git）：変更の要点を日本語1行で書く。コミットとプッシュは指示があるときだけ行う。
