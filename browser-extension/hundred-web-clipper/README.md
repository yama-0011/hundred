# Hundred Web資料の取り込み（Chrome拡張）

製品のマニュアルなどの記事から、ヘッダーのメニューや目次などの不要な部分を外し、本文をMarkdownと画像にして、選んだフォルダへ保存します。Claude CodeやCodexが資料の中身を読めるようにするためのツールです。

## 入れ方

1. Chromeで `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダ（`browser-extension/hundred-web-clipper`）を選ぶ

## 使い方

1. 取り込みたい記事を開き、拡張のアイコンを押す（右側にサイドパネルが開く）
2. はじめてのサイトでは「このサイトの読み取りを許可」を押す
3. 「フォルダを選ぶ」で保存先の親フォルダを選ぶ（例：`ai-desktop-workspace/Web資料`）。中にサイト名のフォルダを作る。サイト名はページから自動で決まり、サイドパネルで変えられる
4. 「範囲を選ぶ」を押し、記事のページで範囲を確認する
   - 緑の枠が本文、赤が除外する部分
   - 「除外を選ぶ」でクリックすると、除外と取り込むが切り替わる
   - 「本文を選ぶ」でクリックすると、その要素を本文にする
   - ↑キーで1つ外側の要素に広げ、↓キーで戻す
   - やめるときは、ページでEscキーを押すか、サイドパネルの「選ぶのをやめる」を押す。サイドパネルを閉じてもやめる
5. 「この記事を保存」を押す

選んだ範囲と保存先はサイトごとに覚えます。同じサイトの次の記事では、範囲を選ばずに「この記事を保存」を押すだけで、同じ範囲で保存します。

## 保存するもの

```text
<選んだフォルダ>/
└── <サイト名>/
    ├── index.md            ← 記事の一覧（タイトル・パンくず・取り込み日・URL）
    └── <記事名>/
        ├── 本文.md         ← 本文（先頭に元のURL・タイトル・パンくず・取り込み日）
        └── 01.png …        ← 本文中の画像
```

- 同じURLの記事を取り込み直すと、同じ記事のフォルダを作り直します。
- 別のドメインにある画像は保存できないことがあります。その場合は、元のURLのまま残します。

## 扱い

- 取り込んだ内容は選んだフォルダにだけ保存し、どのサーバーにも送りません。拡張はサインイン情報を持ちません。
- 記事の中を読むのは、許可したサイトだけです。
- 他社の文章と画像なので、調査用に使います。公開する資料には本文や画像をそのまま載せず、要約と出典のURLにとどめてください。`ai-desktop-workspace/Web資料/` はGitの対象外です。
